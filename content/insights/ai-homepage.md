# 개발 몰라도 AI로 홈페이지 만드는 방법

현재 보고 계신 로고닷 홈페이지는 개발자가 아닌 디자이너가 직접 제작했습니다.

정확히 말하면 저는 HTML, CSS, JavaScript를 전혀 모릅니다.

개발을 배운 적도 없고, 웹사이트를 만들어 본 경험도 없었습니다.

그럼에도 불구하고 로고닷 홈페이지는 제가 직접 만들고 운영하고 있습니다.

물론 처음부터 모든 코드를 직접 작성한 것은 아닙니다.

AI 코딩 도구인 Claude의 도움을 받아 디자인부터 수정, 배포까지 직접 진행했습니다.

몇 년 전만 해도 홈페이지 제작은 개발자의 영역으로 여겨졌지만, 이제는 AI를 활용하면 개발 경험이 거의 없어도 직접 홈페이지를 구축할 수 있는 시대가 되었습니다.

이번 글에서는 제가 실제로 로고닷 홈페이지를 제작하며 경험한 과정을 소개해 보려고 합니다.

---

## 왜 직접 만들게 되었을까?

처음에는 개발자와 함께 홈페이지를 제작했습니다.

하지만 작업이 진행될수록 작은 수정 하나에도 시간이 필요했고, 원하는 결과가 정확하게 반영되지 않는 경우도 있었습니다.

특히 브랜드 홈페이지는 디테일이 중요합니다.

버튼의 크기, 여백, 애니메이션 속도, 모바일 화면에서의 움직임까지 모두 브랜드 경험에 영향을 주기 때문입니다.

수정 요청이 반복될수록 이런 생각이 들었습니다.

> "내가 직접 수정할 수 있다면 훨씬 빠르지 않을까?"

그때부터 AI를 활용해 직접 홈페이지를 만들어보기 시작했습니다.

![Claude Code 작업 화면](/insights/ai-homepage/1.webp)

Claude에게 원하는 내용을 채팅하듯 설명하면 실제 코드를 수정하고 결과를 반영하는 방식입니다.

예를 들어 카드의 크기, 여백, 애니메이션, 모바일 최적화 같은 작업을 직접 요청하며 홈페이지를 개선할 수 있었습니다.

---

## Claude는 어떻게 활용했을까?

제가 사용한 도구는 Claude입니다.

Claude는 원하는 내용을 입력하면 코드를 생성하거나 수정해 주는 AI 도구입니다.

예를 들어 다음과 같은 요청을 할 수 있습니다.

* 버튼에 라임 컬러 호버 효과를 추가해 줘
* 모바일 화면에서 글자가 겹치지 않게 수정해 줘
* 타이핑 애니메이션을 구현해 줘
* 포트폴리오 레이아웃을 수정해 줘
* 페이지 로딩 속도를 개선해 줘

처음에는 코드가 낯설게 느껴졌지만 반복적으로 수정하다 보니 구조를 조금씩 이해하게 되었습니다.

마치 디자인 툴을 처음 배울 때와 비슷했습니다.

처음에는 어렵지만 계속 만지다 보면 어떤 부분을 수정해야 하는지 감이 생깁니다.

물론 저도 처음부터 Claude를 사용할 줄 알았던 것은 아닙니다.

어떤 요청을 해야 하는지 모르겠을 때는 ChatGPT나 Gemini에게 물어보며 사용했습니다.

Claude 설치 방법부터 사용 방법, 오류 해결, 배포 과정까지 모두 AI에게 질문하며 진행했습니다.

예를 들어

"Claude Code는 어떻게 설치하나요?"
"터미널은 어떻게 사용하나요?"
"도메인은 어떻게 연결하나요?"
"이 오류는 왜 발생한 건가요?"

같은 질문을 하면 단계별로 방법을 알려주기 때문에 생각보다 어렵지 않았습니다.

결국 AI를 활용한 개발은 코드를 아는 것보다 원하는 결과를 설명하고 필요한 정보를 찾는 능력이 더 중요하다고 느꼈습니다.

---

## 디자인은 AI가 아닌 사람이 결정합니다

물론 AI가 모든 것을 대신 만들어 주는 것은 아닙니다.

로고닷 홈페이지 역시 디자인 방향은 제가 직접 정했습니다.

브랜드 컬러, 폰트 크기, 여백, 레이아웃, 애니메이션의 분위기까지 먼저 Figma에서 정리한 뒤 Claude를 활용해 실제 웹사이트로 구현했습니다.

즉, AI가 디자인을 만든 것이 아니라 제가 원하는 디자인을 AI가 구현한 것입니다.

물론 Figma 없이도 홈페이지를 제작할 수 있습니다.

하지만 저는 원하는 결과를 더 정확하게 전달하기 위해 먼저 디자인을 정리한 뒤 작업하는 방식을 선택했습니다.

결국 AI는 디자이너의 역할을 대신하는 것이 아니라, 아이디어를 더 빠르게 현실로 만들어 주는 도구에 가깝다고 생각합니다.

---

## 실제 홈페이지 제작 과정

로고닷 홈페이지를 만들 때는 먼저 전체 구조를 정리했습니다.

홈페이지에 필요한 메뉴는 다음과 같았습니다.

* Home
* Process
* Portfolio
* Insights
* Contact

이후 각 페이지에 필요한 내용을 정리하고 Figma에서 디자인 방향을 잡았습니다.

그다음 Claude를 활용해 실제 웹사이트 구조를 만들고 필요한 기능을 하나씩 추가했습니다.

예를 들어 메인 화면에는 로고닷의 핵심 문장인 **"One dot. Infinite identity."** 가 타이핑되는 애니메이션을 적용했습니다.

브랜드 컬러인 라임 컬러를 버튼과 인터랙션 요소에 적용하고 모바일에서도 자연스럽게 보이도록 여러 번 수정했습니다.

결국 홈페이지의 완성도는 거창한 기능보다 작은 디테일을 얼마나 반복해서 다듬느냐에 달려 있었습니다.

![로고닷 홈페이지](/insights/ai-homepage/2.webp)

## 사용한 도구

로고닷 홈페이지 제작에 사용한 도구는 다음과 같습니다.

* Figma
* Claude Code
* Next.js
* Vercel
* Cloudflare

디자인은 Figma에서 진행하고 Claude를 활용해 코드를 수정했습니다.

완성된 홈페이지는 Vercel을 통해 배포하고 Cloudflare로 도메인을 연결했습니다.

처음에는 낯선 과정이 많았지만 한 번 세팅하고 나니 수정과 배포가 생각보다 빠르게 가능했습니다.

---

## AI로 홈페이지를 만들며 느낀 점

가장 큰 장점은 속도였습니다.

예전에는 작은 수정도 개발자에게 요청하고 기다려야 했습니다.

하지만 지금은 아이디어가 떠오르면 바로 적용해 볼 수 있습니다.

디자인과 개발 사이의 거리가 크게 줄어든 것입니다.

또한 브랜드를 가장 잘 이해하는 사람이 직접 수정할 수 있다는 점도 좋았습니다.

브랜드 홈페이지는 단순히 정보를 보여주는 페이지가 아니라 브랜드의 첫인상을 만드는 공간입니다.

그렇기 때문에 컬러, 문장, 여백, 움직임 하나하나가 중요합니다.

반대로 AI가 항상 완벽한 것은 아닙니다.

가끔은 엉뚱한 부분을 수정하기도 하고 원하는 결과를 얻기 위해 여러 번 질문을 바꿔야 할 때도 있습니다.

그래도 개발을 전문적으로 배우지 않았더라도 홈페이지를 직접 만들고 운영할 수 있다는 점은 분명히 큰 변화라고 생각합니다.

---

## 이제는 누구나 만들 수 있는 시대

예전에는 홈페이지를 만들기 위해 개발자를 찾아야 했습니다.

하지만 AI의 등장으로 이제는 아이디어를 가진 사람이 직접 구현까지 시도할 수 있는 환경이 만들어지고 있습니다.

물론 전문 개발자를 완전히 대체할 수는 없습니다.

하지만 브랜드 홈페이지나 포트폴리오 사이트 정도는 충분히 직접 제작할 수 있는 시대가 되었습니다.

현재 보고 계신 로고닷 홈페이지 역시 개발 경험이 전혀 없는 디자이너가 AI를 활용해 직접 제작했습니다.

AI는 디자이너를 개발자로 만들어 주지는 않습니다.

하지만 아이디어를 더 빠르게 현실로 만들 수 있도록 도와주는 강력한 도구임은 분명합니다.

앞으로는 디자인을 잘하는 것뿐만 아니라 좋은 도구를 활용해 빠르게 구현하는 능력도 중요한 경쟁력이 될 것입니다.
